# Arcane Quest (Pygame)

Arcane Quest is a Python-based game built using the [Pygame](https://www.pygame.org/) library. Embark on a magical adventure, overcome challenging obstacles, and enjoy classic gameplay mixed with arcane elements!

## Features

- 🌀 Engaging quest-driven gameplay
- 🕹️ Classic 2D graphics powered by Pygame
- 🎯 Multiple levels and challenges
- ⚡ Power-ups, enemies, and more!

## Installation

1. **Clone the repository:**
    ```bash
    git clone https://github.com/iraklisspyrou/arcane-quest-pygame.git
    cd arcane-quest-pygame
    ```

2. **Create and activate a virtual environment (optional but recommended):**
    ```bash
    python -m venv venv
    # On Windows
    venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

3. **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
    If there’s no `requirements.txt`, install Pygame directly:
    ```bash
    pip install pygame
    ```
